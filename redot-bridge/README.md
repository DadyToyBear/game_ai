# Экспериментальный мост кадров Redot

Это **начальный прототип**, а не готовая система синхронизации. Он состоит из локального HTTP-сервера, MCP-адаптера через stdio и браузерного кода, который с явного согласия пользователя периодически публикует кадр canvas игры. Сервер хранит только последний кадр в оперативной памяти. Он не записывает экран, не синхронизирует файлы и не передаёт видео.

## Безопасность и ограничения

- Сервер намеренно слушает только `127.0.0.1` и работает без TLS. **Не публикуйте его напрямую в интернет.** Для удалённой работы понадобится отдельно спроектированный защищённый сервер, HTTPS/WSS, авторизация и разграничение доступа.
- Каждый HTTP-запрос к кадру требует случайный секрет. Не отправляйте секрет в чат, не записывайте его в репозиторий и не вставляйте в общие файлы конфигурации. На общей машине localhost тоже доступен другим локальным процессам.
- Кадры включаются пользователем. После остановки последний кадр остаётся в памяти сервера до вызова MCP `delete_game_screenshot`, HTTP DELETE или остановки сервера. Если публикация продолжается, новый кадр появится снова.
- MCP `game_screenshot` возвращает **последний полученный** кадр, а не запускает новый захват. Это ограниченная серия снимков, не real-time видео. Доступ к MCP должен быть выдан только доверенному клиенту: он сможет читать и удалять кадры.
- Прототип не проверен с настоящей собранной Web-версией Redot. В частности, `canvas.toBlob` для WebGL может дать чёрный/устаревший кадр или ошибку. `game-canvas` взят из HTML-оболочки Redot 26.3 RC2; реальную работу, запуск игры и отображение нужно проверить после успешной сборки. Оверлей — экспериментальный JS в оболочке, **не встроенный EditorPlugin**.
- На мобильных браузерах, C# и нативном редакторе этот захват не проверялся. Нативному Redot понадобится отдельный отправитель кадров. Браузер и мост в этой версии должны работать на одной машине; агент в облачной песочнице не может автоматически подключиться к localhost пользователя.

## Тест на одной машине

Нужен Python 3.9+. В терминале (Linux/macOS):

```bash
export REDOT_BRIDGE_TOKEN="$(python3 -c 'import secrets; print(secrets.token_hex(32))')"
# Скопируйте выведенный секрет только локально, не в чат:
printf '%s\n' "$REDOT_BRIDGE_TOKEN"
python3 redot-bridge/bridge.py serve
```

Windows PowerShell:

```powershell
$env:REDOT_BRIDGE_TOKEN = python -c "import secrets; print(secrets.token_hex(32))"
# Скопируйте значение только локально, не в чат:
$env:REDOT_BRIDGE_TOKEN
python redot-bridge/bridge.py serve
```

Откройте `http://127.0.0.1:8765/`, введите секрет и включите кадры. Это демонстрационный canvas, не игра Redot. Останавливается кнопкой на странице. Остановка сервера — Ctrl+C.

## MCP-адаптер

Адаптер связывается с сервером на localhost. Запускайте его в процессе MCP-клиента с той же переменной `REDOT_BRIDGE_TOKEN`:

```bash
python3 redot-bridge/bridge.py mcp
```

Он использует JSON-RPC по stdio (MCP protocol `2025-03-26`) и объявляет инструменты `game_screenshot` и `delete_game_screenshot`. Конкретный способ передачи переменной окружения зависит от MCP-клиента. Не сохраняйте секрет в общедоступных конфигурациях. Доступ MCP-клиента к локальной команде или к localhost должен существовать отдельно; данный репозиторий не подключает MCP автоматически к Arena.

## Эксперимент с Web-редактором

Когда Web-редактор Redot **успешно собран**, распакуйте артефакт и запустите мост, указав папку с `godot.editor.html`:

```bash
python3 redot-bridge/bridge.py serve --editor-dir /path/to/unpacked-editor
```

В Windows, например: `python redot-bridge/bridge.py serve --editor-dir C:\\redot-web`.

Откройте `http://127.0.0.1:8765/editor/godot.editor.html`. Сервер подмешивает в HTML небольшую панель «Мост: кадры игры» и добавляет заголовки COOP/COEP. Импортируйте проект, запустите игру, введите секрет в панель и включите передачу. Панель пытается захватить только `#game-canvas`, не canvas редактора. Если игра закрыта или вкладка игры скрыта, передача ждёт. Проверьте возвращённое изображение: успешный HTTP-ответ сам по себе не доказывает, что WebGL-кадр корректен.

## Проверки разработки

```bash
python3 -m unittest discover -s redot-bridge/tests -v
node --check redot-bridge/web/capture.js
node --check redot-bridge/web/redot-overlay.js
node redot-bridge/tests/test_capture.js
```

Тесты проверяют локальные HTTP-авторизацию, кадр, удаление, MCP stdio и оболочку через синтетические данные; они не проверяют Redot или реальный браузер.
