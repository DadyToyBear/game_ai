# Экспериментальный мост кадров Redot

Это **экспериментальный прототип**, а не готовая система синхронизации. Локальный мост, MCP-адаптер и аддон для нативного редактора передают последовательно кадры именно игрового viewport и команды запуска/остановки. Сервер хранит только последний кадр в памяти. Страница может сохранить кадр и записать до 60 секунд этого покадрового предпросмотра в WebM без звука. Полноценный видеострим и синхронизация файлов не реализованы.

## Безопасность и ограничения

- Сервер намеренно слушает только `127.0.0.1` и работает без TLS. **Не публикуйте его напрямую в интернет.** Для удалённой работы понадобится отдельно спроектированный защищённый сервер, HTTPS/WSS, авторизация и разграничение доступа.
- Каждый HTTP-запрос к кадру требует случайный секрет. Не отправляйте секрет в чат, не записывайте его в репозиторий и не вставляйте в общие файлы конфигурации. На общей машине localhost тоже доступен другим локальным процессам.
- Нативный аддон активируется только после установки, ручного добавления автозагрузки и запуска редактора с `REDOT_BRIDGE_ENABLED=1` и секретом. При запущенной игре кадры отправляются автоматически примерно два раза в секунду; это может снижать производительность. Остановите игру или удалите автозагрузку, чтобы прекратить захват. После остановки последний кадр остаётся в памяти сервера до вызова MCP `delete_game_screenshot`, HTTP DELETE или остановки сервера. Если публикация продолжается, новый кадр появится снова.
- MCP `game_screenshot` возвращает **последний полученный** кадр, а не запускает новый захват. `game_status` показывает заявленный источником `frame_source` и возраст кадра; в общем хранилище только один кадр, и другие подключённые источники могут его заменить. Используйте по одному источнику за раз. Это ограниченная серия снимков, не real-time видео. Доступ к MCP должен быть выдан только доверенному клиенту: он сможет читать и удалять кадры.
- Прототип не проверен с настоящей собранной Web-версией Redot. В частности, `canvas.toBlob` для WebGL может дать чёрный/устаревший кадр или ошибку. `game-canvas` взят из HTML-оболочки Redot 26.3 RC2; реальную работу, запуск игры и отображение нужно проверить после успешной сборки. Оверлей — экспериментальный JS в оболочке, **не встроенный EditorPlugin**.
- Нативный аддон **ещё не проверен в реальном Redot**; проверен только синтаксис GDScript и взаимодействие Python-моста с имитацией клиента. На мобильных браузерах и в C# он тоже не проверен. Минимизация окна, headless-режим или особенности рендерера могут препятствовать захвату. Запуск плагина и кадры реальной игры необходимо проверить вручную.
- Браузер, мост и редактор в этой версии должны работать на одной машине; агент в облачной песочнице не может автоматически подключиться к localhost пользователя. Код не реализует удалённое подключение через интернет или синхронизацию проектов.

## Тест на одной машине

Нужен Python 3.9+. В терминале (Linux/macOS):

```bash
export REDOT_BRIDGE_TOKEN="$(python3 -c 'import secrets; print(secrets.token_hex(32))')"
# Скопируйте выведенный секрет только локально, не в чат:
printf '%s\n' "$REDOT_BRIDGE_TOKEN"
python3 redot-bridge/bridge.py serve
```

Windows PowerShell:

```powershell
$env:REDOT_BRIDGE_TOKEN = python -c "import secrets; print(secrets.token_hex(32))"
# Скопируйте значение только локально, не в чат:
$env:REDOT_BRIDGE_TOKEN
python redot-bridge/bridge.py serve
```

Откройте `http://127.0.0.1:8765/`, введите секрет и включите кадры. Это демонстрационный canvas, не игра Redot. Останавливается кнопкой на странице. Остановка сервера — Ctrl+C.

## Нативный Redot: установка аддона (эксперимент)

1. Скопируйте папку `addons/redot_local_bridge` из этого архива/папки в `addons/redot_local_bridge` вашего **проекта** Redot. Не перезаписывайте одноимённый существующий аддон. Работайте на резервной копии проекта.
2. В редакторе откройте Project → Project Settings → Plugins и включите **Redot Local Game Bridge**.
3. Там же в Project Settings → Globals → Autoload (или вкладка Autoload в зависимости от версии) вручную добавьте `res://addons/redot_local_bridge/game_bridge.gd` под новым именем, например `RedotLocalBridgeGame`. Это изменит настройки проекта. Плагин не добавляет и не удаляет автозагрузку автоматически. Перед распространением/релизом удалите автозагрузку и отключите плагин.
4. Полностью закройте редактор. В PowerShell перейдите в папку, содержащую `bridge.py` и `web` (из распакованного комплекта). Создайте временный секрет и запустите Redot из этого же окна, чтобы редактор и его дочерняя игра унаследовали переменные среды:

   ```powershell
   $env:REDOT_BRIDGE_ENABLED = '1'
   $env:REDOT_BRIDGE_TOKEN = python -c "import secrets; print(secrets.token_hex(32))"
   # Скопируйте вывод только локально, никогда не отправляйте в чат:
   $env:REDOT_BRIDGE_TOKEN
   Start-Process -FilePath 'C:\\путь\\к\\Redot.exe'
   python bridge.py serve
   ```

   Укажите реальный путь к своему EXE. Выберите свой проект в открывшемся Redot. Сервер занимает терминал; для остановки нажмите Ctrl+C. Бинарный установщик Redot в этот комплект не входит. Секрет действует до закрытия сервера; запуск из обычного ярлыка или повторно открытый уже запущенный редактор может не унаследовать переменные.
5. Откройте **http://127.0.0.1:8765/native.html** на этой же машине, введите секрет и нажмите «Подключить». После того как аддон начнёт отправлять heartbeat, можно нажать Play/Stop на странице или в редакторе. Игра должна быть запущена для появления кадров. Кнопка «Скачать кадр» сохраняет последний кадр на компьютер, а WebM записывает покадровый просмотр, не окно редактора и не рабочий стол.
6. Если статус не меняется: проверьте, что редактор закрыли и запустили именно из PowerShell с переменными, плагин включён, автозагрузка добавлена, а консоль сервера работает на порту 8765. При чёрном экране или отсутствии кадров не сворачивайте игру, проверьте рендерер и сообщения Output/Debugger.

Play/Stop управляет основной сценой редактора. Это действие меняет состояние проекта/игры и доступно всем клиентам, знающим секрет. Команда в очереди не гарантирует, что игра стартовала: проверяйте status и ошибки редактора. Код работает только с одиночным локальным редактором и не выполняет удалённое подключение к Arena.

## MCP-адаптер

Адаптер связывается с сервером на localhost. Запускайте его в процессе MCP-клиента с той же переменной `REDOT_BRIDGE_TOKEN`:

```bash
python3 redot-bridge/bridge.py mcp
```

Он использует JSON-RPC по stdio (MCP protocol `2025-03-26`) и объявляет инструменты `game_screenshot`, `delete_game_screenshot`, `game_play`, `game_stop` и `game_status`. Play/Stop ставят команду в очередь; `game_status` показывает последнее состояние редактора, а не гарантию исполнения. Конкретный способ передачи переменной окружения зависит от MCP-клиента. Не сохраняйте секрет в общедоступных конфигурациях. Доступ MCP-клиента к локальной команде или к localhost должен существовать отдельно; данный репозиторий не подключает MCP автоматически к Arena.

## Эксперимент с Web-редактором

Когда Web-редактор Redot **успешно собран**, распакуйте артефакт и запустите мост, указав папку с `godot.editor.html`:

```bash
python3 redot-bridge/bridge.py serve --editor-dir /path/to/unpacked-editor
```

В Windows, например: `python redot-bridge/bridge.py serve --editor-dir C:\\redot-web`.

Откройте `http://127.0.0.1:8765/editor/godot.editor.html`. Сервер подмешивает в HTML небольшую панель «Мост: кадры игры» и добавляет заголовки COOP/COEP. Импортируйте проект, запустите игру, введите секрет в панель и включите передачу. Панель пытается захватить только `#game-canvas`, не canvas редактора. Если игра закрыта или вкладка игры скрыта, передача ждёт. Проверьте возвращённое изображение: успешный HTTP-ответ сам по себе не доказывает, что WebGL-кадр корректен.

## Проверки разработки

```bash
python3 -m unittest discover -s redot-bridge/tests -v
node --check redot-bridge/web/capture.js
node --check redot-bridge/web/redot-overlay.js
node redot-bridge/tests/test_capture.js
node redot-bridge/tests/test_native.js
```

Тесты проверяют локальные HTTP-авторизацию, кадр, удаление, MCP stdio и оболочку через синтетические данные; они не проверяют Redot или реальный браузер.
