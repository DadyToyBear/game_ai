Из установленного Redot в Web-редактор

Сохрани изменения в настольном редакторе. Снимок может содержать приватные файлы проекта. Скачать ZIP, затем выбрать его на стартовой странице Web-редактора в «Preload project ZIP».

Открыть Web-редактор, если подключён

Из Web-редактора на компьютер

В Web-редакторе: Project → Tools → Download Project Source. Выбери скачанный ZIP ниже. Он будет распакован в новую соседнюю папку; оригинал не изменится.
