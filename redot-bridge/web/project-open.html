Подготовить копию проекта для Redot

Эта страница скачивает ZIP на устройство; она не открывает его в Android-редакторе автоматически. В менеджере проектов Android выберите Import и укажите ZIP или локальную папку с project.godot. Выбирайте новую пустую папку назначения.

Ссылка должна непосредственно возвращать ZIP, а сервер — разрешать CORS. Ссылки с перенаправлением, без CORS или требующие входа через браузерные cookies не поддерживаются. Удалённый HTTP не защищает ваши файлы; допускается только HTTPS или локальный HTTP.
