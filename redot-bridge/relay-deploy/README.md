# Экспериментальный HTTPS relay для Android и MCP

**Не готовый публичный сервис.** Этот код — одиночная сессия для доверенного владельца: не размещён автоматически и не подключает Arena к MCP. Для запуска нужен свой сервер, домен, действующий публично доверенный TLS-сертификат и администрирование. Плагин Android и реальный интернет-маршрут пока не проверены на устройстве. Если нет своего защищённого сервера, продолжайте использовать USB из `../README.md`.

Relay принимает heartbeat/Play/Stop и кадры из запущенной игры; браузер получает отдельные кадры, MCP по stdio может получить или удалить последний. Два разных секрета: **device** разрешает передавать кадры и получать команды, **controller** позволяет читать/удалять кадры и управлять Play/Stop. Секрет controller даёт доступ к управлению редактором, поэтому выдавайте его только полностью доверенным клиентам. Любой, знающий device-секрет, может выдавать себя за редактор и отправлять другие изображения. Не является сквозным шифрованием: оператор сервера и его инфраструктура видят незашифрованные кадры и секреты. Нет live-синхронизации файлов, логов, полноценного потокового видео, аудио, независимых пользователей, изоляции нескольких редакторов или автоматического истечения ключей.

## Безопасность и развёртывание

- Используйте отдельный домен, не размещайте на нём другие приложения/пользовательский HTML. Relay должен работать на доверенном сервере за корректно настроенным reverse proxy с TLS, лимитами соединений и запросов, тайм-аутами и ограничением размера тела. Пример `nginx.example.conf` **нужно адаптировать** и проверить `nginx -t`; он не выпускает сертификат и не настраивает firewall автоматически. Разрешите извне только 443; не открывайте порт 8766. Адрес приложения принудительно `127.0.0.1`; другие процессы на этом сервере могут обращаться к нему в обход proxy, поэтому сервер и локальные пользователи должны быть доверенными.
- Держите ОС, Python, aiohttp и nginx обновлёнными, используйте отдельного непривилегированного пользователя и, где возможно, VPN/IP allowlist. Выключены HTTP access logs приложения и примера proxy, но проверьте свои логи/мониторинг. Не размещайте секреты в репозитории, URL, командной строке, чатах и общедоступных настройках. Ограничения в примере proxy не заменяют полноценный аудит и защиту от DoS. Приложение не является многопользовательским или прошедшим аудит.
- Сгенерируйте два **разных** случайных секрета, например отдельно локально командой `python3 -c 'import secrets; print(secrets.token_hex(32))'`. Секреты задаются процессу relay через переменные `REDOT_RELAY_DEVICE_TOKEN` и `REDOT_RELAY_CONTROLLER_TOKEN` безопасным способом (для systemd — защищённый root-only EnvironmentFile). Меняйте их после компрометации и перезапускайте relay. Перезапуск уничтожает последний кадр и очередь, но не удаляет уже скачанные копии.
- Установите зависимости из `requirements-relay.txt`. В каталоге с `relay.py`, `bridge.py`, `project_sync.py` и `web/` запустите **на сервере** с двумя переменными в окружении:

  ```bash
  python3 relay.py --origin https://ваш-домен.example
  ```

  Замените домен на реальный нижним регистром, без пути и завершающего слэша. Это значение должно совпадать с внешним HTTPS Origin/Host в запросе; для нестандартного порта указывайте `:порт` и настройте proxy соответствующим образом. Пример nginx ожидает loopback `8766`; при изменении `--port` измените и конфигурацию proxy. Никогда не публикуйте порт Python-приложения напрямую.

## Подключение

1. В редакторе Android включите `redot_android_mcp`, откройте Project → Tools → MCP Bridge, введите адрес `https://ваш-домен.example` и **device**-секрет. Для игры добавьте `game_capture.gd` как Autoload (см. инструкцию Android) и в её диалоге отдельно введите этот же адрес и device-секрет. Для USB оставьте `http://127.0.0.1:8765`; другие HTTP-адреса запрещены. Для HTTPS проверяется системный сертификат, редиректы отключены. Секреты не сохраняются скриптами в проекте.
2. Откройте на доверенном устройстве `https://ваш-домен.example/native.html`, введите **controller**-секрет. Кадры появятся только после согласия в игре и успешной работы рендерера/сети. Удаление последнего кадра не останавливает повторную отправку: остановите игру.
3. Для MCP-клиента запустите `python bridge.py mcp --url https://ваш-домен.example` с **controller**-секретом в `REDOT_BRIDGE_TOKEN`. У клиента должен быть исходящий HTTPS и он должен поддерживать запуск stdio MCP. Сертификат проверяется, редиректы не следуются. Relay не предоставляет endpoints проекта; соответствующие MCP-инструменты вернут ошибку.

HTTPS — обязательное условие внешнего доступа: публичный HTTP, самоподписанный сертификат, пересылка секретов по ссылкам и обход проверки TLS не поддерживаются. Если в браузере и у MCP-клиента нет доступа к серверу, этот вариант не заработает. Подключение к платформе Arena зависит от её возможностей настройки MCP и данным кодом не предоставляется автоматически.
