# Aurora Files

Независимый файловый менеджер Android, не связанный с Cx File Explorer. Android 8.0 и новее.

## Возможности

* Доступ к выбранной папке через Storage Access Framework: просмотр, открытие и отправка файлов, создание папок, переименование и удаление (долгое нажатие). Доступные операции зависят от провайдера; удаление необратимо.
* Копирование и вырезание с последующей вставкой, ZIP-упаковка и распаковка в новую папку. Операции требуют поддержки провайдера и могут оставить частичные данные при сбоях. Распаковка ограничена 10 000 элементов и 1 ГиБ, опасные пути отклоняются. Архивы других форматов и зашифрованные ZIP не поддерживаются.
* Текстовый редактор UTF-8 с сохранением исходного файла, до 1 МиБ. При сбое сохранения файл может оказаться неполным — перед редактированием делайте копию.
* Изображения, видео, MP3 и WAV открываются через совместимые приложения Android; встроенного проигрывателя нет.
* SSH: подключение по паролю и выполнение одной команды за соединение. Каждый раз вручную сравните SHA-256 отпечаток ключа сервера с полученным по независимому каналу. Пароли не сохраняются. Интерактивный терминал, ключи клиента, SFTP и проброс портов пока не поддерживаются. Вывод ограничен 64 КиБ на поток.
* Web-доступ: выберите папку, затем запустите сервер. Браузер предоставляет только просмотр и скачивание. WebDAV находится по адресу `http://IP:порт/dav/`: OPTIONS, PROPFIND (Depth 0 или 1), GET, HEAD; при отдельном включении записи — также PUT, MKCOL, DELETE, COPY и MOVE. По умолчанию запись выключена, а при анонимном доступе она запрещена. Публикуется корень последней выбранной папки, не текущая подпапка. Это HTTP-сервер, **не FTP**. Сервер прекращает работу при уничтожении экрана приложения (в том числе при пересоздании после поворота), может быть остановлен системой и не предназначен для фоновой работы.
  PUT создаёт или перезаписывает файл, DELETE необратимо удаляет файл или папку. Максимум 256 МиБ на загрузку; нужен Content-Length и свободное место в кэше. Chunked и частичная загрузка, заголовок Expect, блокировки и ETag не поддерживаются. COPY и MOVE работают только внутри опубликованной папки и не перезаписывают существующее назначение (даже при Overwrite: T); папки копируются целиком. MOVE выполняется как копирование с последующим удалением: при ошибке удаления останутся оба объекта. При ошибке копирования частичная копия удаляется по возможности, но некоторые провайдеры могут её оставить. При обрыве загрузки существующий файл не меняется, но при последующей ошибке записи провайдера может быть повреждён: атомарной замены нет. Функциональность и совместимость WebDAV-клиентов на устройстве не проверены; поддержка операций зависит от провайдера документов.
* Простой Paint с сохранением PNG, ICMP ping через системную команду.

**Безопасность Web-доступа:** HTTP не шифрует ни файлы, ни пароль; Basic-аутентификация не защищает от перехвата в сети. Сервер слушает доступные интерфейсы устройства, а анонимный режим открывает файлы любому, кто может к нему подключиться. В режиме записи любой, кто получил пароль, может изменить или удалить файлы. Используйте только в доверенной локальной сети, не открывайте порт в интернет и остановите сервер после использования. Не применяйте важные пароли.

Android 11+ ограничивает выбор некоторых папок, включая Android/data и корень внутреннего хранилища. Облачные документы доступны только через системные провайдеры, не через собственную интеграцию. Для открытия многих файлов необходим сторонний просмотрщик.

## Сборка APK

Откройте проект в Android Studio с JDK 17 и Android SDK 35, дождитесь синхронизации Gradle и выберите **Build → Build APK(s)**. Debug APK: `app/build/outputs/apk/debug/app-debug.apk`. Нужен интернет для загрузки Android Gradle Plugin и зависимостей JSch и NanoHTTPD. Для публикации нужна собственная подпись release-версии.

В проект добавлен Gradle Wrapper 8.9 с проверкой SHA-256: при наличии полного JDK 17 и Android SDK 35 можно также выполнить `./gradlew :app:assembleDebug` (Windows: `gradlew.bat :app:assembleDebug`). Wrapper скачивает Gradle при первом запуске.

В репозитории предусмотрен GitHub Actions workflow **Build Android debug APK** (`.github/workflows/android-debug.yml`): он устанавливает JDK и SDK, собирает debug APK и прикрепляет артефакт `aurora-files-debug` к запуску на 14 дней. Он запускается после push изменений проекта в текущую ветку или вручную через вкладку Actions. Debug APK подписан стандартным временным debug-ключом, а не ключом для публикации.

В среде Arena удалось установить только Java Runtime 17 без компилятора; доступ к официальным сайтам Gradle и Android SDK заблокирован. Wrapper здесь не смог скачать Gradle, а workflow пока не запускался. APK не собран и работа на устройстве не проверена.

## Далее

FTP/FTPS/SFTP/SMB, полноценный WebDAV (блокировки, перезапись при MOVE/COPY), TLS, постоянные локальные учётные записи, SSH-терминал и проброс портов, удалённый рабочий стол, видеоредактор, корзина и анализ хранилища пока не реализованы. Их можно добавлять отдельными обновлениями.

## Ручная проверка WebDAV

Выберите тестовую папку с копиями файлов, включите запись и пароль. На компьютере в доверенной сети замените адрес и используйте свой логин; `curl -u login` запросит пароль без записи его в командную строку.

```sh
curl -u login -X PROPFIND -H 'Depth: 1' http://IP:8080/dav/
curl -u login -X MKCOL http://IP:8080/dav/test/
curl -u login -T sample.txt -H 'Expect:' http://IP:8080/dav/test/sample.txt
curl -u login -o downloaded.txt http://IP:8080/dav/test/sample.txt
curl -u login -X DELETE http://IP:8080/dav/test/sample.txt
```

Проверьте также отказ без пароля, при выключенной записи и при анонимном режиме; прерванную загрузку, превышение лимита и несовместимый провайдер. Сервер и тесты не запускались в этой среде.

Для проверки COPY и MOVE на отдельной **тестовой** папке можно запустить `tests/webdav_smoke.py`, задав переменные `AURORA_DAV_URL`, `AURORA_DAV_USER`, `AURORA_DAV_PASSWORD` (скрипт создаёт и удаляет тестовые данные). Интеграционный тест требует работающего приложения и не был запущен в этой среде.
