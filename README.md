# Mini Studio — мини-приложение в духе Caustic 3 (браузер, Web Audio)

Небольшая мобильная музыкальная студия: стойка виртуальных машин, степ-секвенсор,
пиано-ролл, микшер с эффектами, MIDI-вход и экспорт в WAV. Всё на чистом JS,
без сборки и зависимостей.

## Запуск

Открыть `index.html` напрямую или поднять статический сервер:

```bash
python3 -m http.server 8080
```

Затем http://localhost:8080

## Что внутри

| Модуль | Тип | Что делает |
| --- | --- | --- |
| BeatBox | драм-машина | 8 каналов (kick/snare/hats/clap/toms/rim), свои WAV в каждый канал |
| PCMSynth | сэмплер | играет ваш WAV по нотам с транспонированием, фильтр + ADSR |
| Subsynth | субтрактивный | 2 детюн-осциллятора + суб, фильтр с конвертом |
| BassLine | моно 303 | резонансный фильтр, accent, драйв |
| FMSynth | FM 3-оп | 2 модулятора, конверт индекса |
| PadSynth | пэд | до 6 расстроенных пил, медленный конверт |
| 8BitSynth | чиптюн | импульсная волна со скважностью, квантование битов, вибрато |

- **Свой секвенсор у каждой машины.** У каждого синтезатора — отдельный пиано-ролл
  со своим банком A/B/C/D, своей высотой дорожек и своими настройками; у драм-машины —
  свой шаговый секвенсор по восьми подушкам прямо в её корпусе. Роллы не смешиваются:
  ноты одной машины не видны в секвенсоре другой.
- **Пиано-ролл** (в корпусе машины и на вкладке «Секвенсор»): ноты-прямоугольники
  по высоте и времени, перетаскивание по сетке, изменение длины за правый край,
  громкость точкой, правый клик — удалить. Светлый бегунок показывает играющий шаг.
- **Операции над своим паттерном**: «×2» (дублировать ноты во второй такт),
  «Сдвиг ±1», транспонирование «±12», масштаб клавиш (70–180 %) и режим
  «Следовать», который прокручивает ролл к играющему такту. Настройки
  сохраняются вместе с проектом и у каждой машины свои.
- **Редактор паттернов**: банк A/B/C/D на каждую машину, копирование паттернов,
  мини-превью блоков и строка «Сцены», где буквами задаётся, какой паттерн играет
  в каком такте аранжировки (A A B A и т. п.). Экспорт рендерит именно аранжировку.
  Блоки разных машин отделены линией и своим цветом, у мелодических машин дорожки
  выше — по ним проще попадать пальцем; `[` и `]` переключают машину.
- Kaoss: смена BPM на ходу перезапускает запущенные лупы на новом темпе (раньше
  шаг замирал на старом и луп расходился с транспортом).
- После остановки панель паттерна показывает тот такт, на котором вы остановились,
  а не первый — подсказка «Играет X» больше не врёт.
- Телефон: панель LINK больше не накрывает приборы Kaoss-деки, пэды ограничены
  по высоте (прибор влезает в экран целиком, в горизонтали — тоже), липкие
  панели ролла/сетки встают под топбар и не прячут кнопки.
- Загрузка проекта проверяет данные: темп, число шагов, длина аранжировки, EQ,
  параметры машин и банки A–D приводятся к безопасным значениям — битый или
  чужой `.json`/`.zip` не ломает студию и не запускает рендер на сотни тактов.
- Драм-машина: своя панель операций — «×2», «Сдвиг ±1», «Сдвиг ½», «Воббл»
  (прореживает повторные удары, сильные доли остаются), «Очистить».
- Тач: сетку секвенсора можно тянуть пальцем — свайп больше не переключает ноту
  (срабатывает только короткий тап без сдвига).
- Превью ноты: клик по пустому месту пиано-ролла играет короткую ноту (~0.3 с) и
  гаснет сам; страховка гасит превью при уходе фокуса/сворачивании вкладки —
  «залипший» звук больше не требует нажимать «Стоп».
- Микшер: громкость/панорама/посылы на каждый канал, шины delay и reverb,
  время дилея считается от темпа (пунктирная восьмая) и совпадает с экспортом.
  мастер с 3-полосным EQ и лимитером.
- MIDI: Web MIDI API, ноты играют на выбранной машине, CC1 → срез фильтра,
  запись при включённом REC — всегда в тот паттерн, который реально звучит
  в этом такте (если сцена играет B, а редактор смотрит на A, запись сама
  переключится на B и скажет об этом тостом: записанное сразу слышно).
- **Экспорт аудио** (вкладка «Экспорт»): офлайн-рендер аранжировки в
  **WAV** (16 бит / 44.1 кГц, без потерь) и **MP3** (128–320 кбит/с, кодировщик
  LAME на чистом JS в `vendor/lame.min.js` — всё считается в браузере, файл никуда
  не отправляется). Прогресс-бар показывает рендер и процент кодирования.
- **MIDI (SMF type 1)** для DAW/Nexus — отдельной кнопкой.
- **Сохранения проектов**: слоты в браузере (до 20 версий с именем, датой,
  числом дорожек/нот/BPM, переименованием и удалением), быстрое сохранение
  из топбара и по Ctrl+S, скачивание/загрузка `.json`, восстановление
  автосохранения (пишется только при изменениях). В проект входит и состояние
  Kaoss-деки: выбранный звук, гамма, октава, FX-программа и записанные лупы.
  Свои WAV-сэмплы в JSON не попадают — это аудио, а не ноты.
- **Проект в ZIP вместе с сэмплами**: «Скачать .zip с сэмплами» собирает архив
  (`project.json` + `samples/*.wav` 16 бит + `README.txt`) прямо в браузере, без
  сторонних библиотек: свои записи WAV, сэмпл Kaossilator и файл плеера miniKP2
  едут вместе с нотами. «Открыть .zip» разбирает такой архив (включая обычные
  ZIP с deflate через `DecompressionStream`) и ставит сэмплы на свои места —
  по манифесту внутри `project.json`.
- **Kaoss-модули** (вкладка «Kaoss») — веб-аналоги железа Korg:
  - **Kaoss Deck** — два прибора стоят рядом на одной «столешнице», как настоящее железо
    (Kaossilator слева, mini Kaoss Pad 2 справа): общий бар с LINK / REC XY / В ЛУП /
    CLEAR, корпуса с текстурами шлифованного алюминия и стеклянных пэдов, LCD с бегущей
    строкой, LED, винты, вентиляционные щели и анимации (рябь при касании, трейл пальца,
    зеркальная «призрачная» точка второго прибора).
  - **LINK — совместная манипуляция**: включите LINK и ведите пальцем по любому пэду —
    второй прибор повторяет движение. Kaossilator играет ноту, miniKP2 одновременно
    открывает фильтр/эхо; индикатор LINK показывает текущую позицию X.
  - **REC XY → В ЛУП**: бар записывает путь пальца (X-Y), кнопка «В ЛУП» превращает его
    в зацикленную фразу Kaossilator в слоте LOOP 1, «CLEAR» стирает путь.
  - **Kaossilator 2-подобный X-Y синтезатор**: горизонталь — нота по выбранной гамме
    (пентатоника, блюз, дорийский и др.), вертикаль — яркость/срез; глиссандо по пэду;
    два лупа — запись фразы и зацикливание поверх (как Kaossilator 2).
  - **Банк из 25 звуков**, как на железе: басы (Sub, Acid 303, Reese, FM Bass),
    лиды (Saw, Square, Chip, FM Bell), плаки (Pluck, Glass, Marimba), пэды
    (Warm, Glass, Strings), чиптюн, ударные (Drum Kit, Toms, Hats & Claps)
    и готовые лупы — басовые, мелодические и драм-лупы (кнопка «▶ луп»).
  - **mini Kaoss Pad 2-подобный X-Y процессор**: 12 программ (LP/HP/BP фильтры,
    флэнжер, хорус, эхо, реверб, vinyl break, гейт, дисторшн, crush, ring mod);
    врезается в мастер-шину или в выбранные каналы.
  - **Свои сэмплы (WAV/MP3/OGG)**: загрузка в оба модуля. У Kaossilator сэмпл
    режется на слайсы (ровно / по пикам) и играет по X, режимы «X = слайс»,
    «X = питч ±12 ст», «X = скорость ×0.5…×2». У miniKP2 есть плеер с pitch adjust
    и зацикливанием — как у железного MP3-плеера. Сэмплерные фразы тоже пишутся в лупы.
  - **HOLD** — фиксация X-Y после отпускания пальца (у синтезатора держит ноту, у FX —
    положение и глубину эффекта), выключение плавно возвращает в нейтраль.
  - **MIDI-управление**: CC1/CC16 → X, CC2/CC17 → Y; ноты 36–43 на 10-м канале
    запускают слайсы 1–8. Работает с любым MIDI-контроллером пэдов.
  - **Луп → паттерн**: кнопка «→ Паттерн» переносит записанную фразу в банк A–D
    выбранной машины как обычные ноты (шаг, высота, длительность, velocity),
    с режимами «заменить» и «добавить».
- Горячие клавиши: `Space` — play/stop, `Z–M`/`Q–U` — клавиатура, `A–K` — подушки BeatBox.
- Нота хранится как `{ at, m, len, v }` — шаг, высота, длина в шагах, громкость.

## Про VST и библиотеки Nexus (reFX)

Браузер не может загружать нативные VST/VST3 и закрытые банки вроде Nexus
(`.nks` / `.ncw`): у веб-страницы нет доступа к плагинам ОС, а формат reFX
расшифровывается только самим Nexus. `Nexus 5 v5.1` — это тот же плагин/хост,
он тоже не «открывает» свой звук для браузера.

**Рабочий мост — экспорт MIDI.** Кнопка «Экспорт MIDI» пишет SMF type 1:

- один трек на каждую машину (имя трека = имя машины);
- ударные BeatBox раскладываются на 10-й MIDI-канал по GM-карте;
- длительности нот из пиано-ролла сохраняются;
- сцены A–D разворачиваются в такты аранжировки, как при воспроизведении.

Дальше в DAW: импорт `.mid` → на каждую дорожку ставится Nexus → выбор пресета
из библиотеки → рендер. Из нашего проекта переносится только MIDI (ноты, высоты,
длительности, velocity), звук даёт Nexus.

**Вариант 2 — MIDI-выход в реальном времени.** Кнопка «MIDI» включает Web MIDI,
в разделе «Экспорт» выбирается порт вывода (loopMIDI, IAC, виртуальный порт DAW).
Транспорт студии шлёт note-on/note-off, velocity, длину и часы F8 прямо в Nexus,
открытый в DAW: FL Studio → MIDI Settings → input port → плагин Nexus в Channel Rack.
Ударные BeatBox уходят на 10-й канал, живая клавиатура студии — на выбранный канал.

### Почему нельзя «просто загрузить Nexus как плагин»

`Nexus 5` — это VST3/AU/AAX-плагин и закрытый движок reFX. В FL Studio и других
DAW он грузится, потому что те имеют доступ к нативным плагинам ОС. Веб-приложение
такого доступа не имеет: `.vst3` не запускается в браузере, `.nks`/`.ncw` не
расшифровываются без самого Nexus. Обойти это можно только нативной оболочкой
(Electron/Tauri + VST-хост вроде JUCE), но это уже не веб-страница.

## Файлы

```
index.html      разметка: транспорт, стойка, секвенсор, микшер, экспорт
css/style.css   тёмная тема, адаптив под телефон
js/engines.js   описания машин, параметров и пресетов
js/pattern.js   банк паттернов A–D, сцены и компонент пиано-ролла
js/midi-file.js экспорт Standard MIDI File (для DAW и Nexus)
js/kaoss.js     X-Y синтезатор с лупом и X-Y процессор эффектов (Web Audio)
js/kaoss-ui.js  X-Y пэды, лупы и сетка программ эффектов
js/audio.js     Web Audio: голоса, барабаны, эффекты, офлайн-рендер, WAV
js/ui.js        кнобы, тосты, модалки
js/app.js       состояние проекта, секвенсор, MIDI, экспорт
```

## Телефон и планшет

- **Тач-режим**: X-Y пэды, ручки и сетка работают пальцем; кнопки не меньше 40 px,
  скрыты лишние подписи, учтены «челки» и безопасные зоны (`env(safe-area-inset-*)`).
  Сетку паттерна можно тянуть пальцем, двойной тап не зумит страницу,
  на нажатия музыкальных элементов идёт лёгкая вибро-отдача.
- **Пэд-режим** (кнопка «Пэд» в топбаре): два прибора на весь экран, панели прячутся,
  запрашивается полноэкранный режим и горизонтальная ориентация — играть большими пальцами.
- **PWA**: `manifest.webmanifest` + иконки + `sw.js` — «Добавить на главный экран»,
  запуск без адресной строки, работа офлайн. Ярлыки манифеста ведут сразу на `#kaoss` и `#io`.
- **APK**: Capacitor-обёртка в `android/` (см. `android/README-APK.md`). CI собирает
  на каждый пуш: устанавливаемый debug APK — в релизе
  [`apk-latest`](https://github.com/DadyToyBear/game_ai/releases/tag/apk-latest),
  подписанные release APK и AAB — в релизе
  [`release-latest`](https://github.com/DadyToyBear/game_ai/releases/tag/release-latest).
- **Release и Google Play**: подпись берётся из GitHub Secrets (`ANDROID_KEYSTORE_BASE64`
  и пароли) или из `android/keystore.properties`; ключ создаётся скриптами
  `scripts/gen-keystore.sh` (JDK) и `scripts/make-signing-key.py` (Python + OpenSSL).
  CI собирает **AAB** для Play Console, проверяет подпись через `apksigner` и публикует
  только подписанные файлы.
- **Сборка без Android SDK**: `bash scripts/install-toolchain.sh` ставит в `tools/`
  JDK, `aapt2` (build-tools 34), `android.jar` API 34, `apktool` и подписчик
  `apk_sign_ts`; `bash scripts/build-apk-local.sh` собирает и подписывает APK
  (v1 + v2) без Gradle и без Maven Central. Подробности:
  [`android/standalone/README.md`](android/standalone/README.md).
