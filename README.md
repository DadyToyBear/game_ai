# Mini Studio — мини-приложение в духе Caustic 3 (браузер, Web Audio)

Небольшая мобильная музыкальная студия: стойка виртуальных машин, степ-секвенсор,
пиано-ролл, микшер с эффектами, MIDI-вход и экспорт в WAV. Всё на чистом JS,
без сборки и зависимостей.

## Запуск

Открыть `index.html` напрямую или поднять статический сервер:

```bash
python3 -m http.server 8080
```

Затем http://localhost:8080

## Что внутри

| Модуль | Тип | Что делает |
| --- | --- | --- |
| BeatBox | драм-машина | 8 каналов (kick/snare/hats/clap/toms/rim), свои WAV в каждый канал |
| PCMSynth | сэмплер | играет ваш WAV по нотам с транспонированием, фильтр + ADSR |
| Subsynth | субтрактивный | 2 детюн-осциллятора + суб, фильтр с конвертом |
| BassLine | моно 303 | резонансный фильтр, accent, драйв |
| FMSynth | FM 3-оп | 2 модулятора, конверт индекса |
| PadSynth | пэд | до 6 расстроенных пил, медленный конверт |
| 8BitSynth | чиптюн | импульсная волна со скважностью, квантование битов, вибрато |

- **Пиано-ролл в каждой машине** (и на вкладке «Редактор паттернов»): ноты-прямоугольники
  по высоте и времени, перетаскивание по сетке, изменение длины за правый край,
  громкость точкой, правый клик — удалить.
- **Редактор паттернов**: банк A/B/C/D на каждую машину, копирование паттернов,
  мини-превью блоков и строка «Сцены», где буквами задаётся, какой паттерн играет
  в каком такте аранжировки (A A B A и т. п.). Экспорт рендерит именно аранжировку.
- Микшер: громкость/панорама/посылы на каждый канал, шины delay и reverb,
  мастер с 3-полосным EQ и лимитером.
- MIDI: Web MIDI API, ноты играют на выбранной машине, CC1 → срез фильтра,
  запись в паттерн при включённом REC.
- Экспорт: офлайн-рендер в WAV 16 бит/44.1 кГц, **MIDI (SMF type 1)** для DAW/Nexus,
  сохранение/загрузка проекта в JSON, автосохранение в localStorage.
- **Kaoss-модули** (вкладка «Kaoss») — веб-аналоги железа Korg:
  - **Kaossilator 2-подобный X-Y синтезатор**: горизонталь — нота по выбранной гамме
    (пентатоника, блюз, дорийский и др.), вертикаль — яркость/срез; глиссандо по пэду;
    два лупа — запись фразы и зацикливание поверх (как Kaossilator 2).
  - **mini Kaoss Pad 2-подобный X-Y процессор**: 12 программ (LP/HP/BP фильтры,
    флэнжер, хорус, эхо, реверб, vinyl break, гейт, дисторшн, crush, ring mod);
    врезается в мастер-шину или в выбранные каналы.
  - **Свои сэмплы (WAV/MP3/OGG)**: загрузка в оба модуля. У Kaossilator сэмпл
    режется на слайсы (ровно / по пикам) и играет по X, режимы «X = слайс»,
    «X = питч ±12 ст», «X = скорость ×0.5…×2». У miniKP2 есть плеер с pitch adjust
    и зацикливанием — как у железного MP3-плеера. Сэмплерные фразы тоже пишутся в лупы.
  - **HOLD** — фиксация X-Y после отпускания пальца (у синтезатора держит ноту, у FX —
    положение и глубину эффекта), выключение плавно возвращает в нейтраль.
  - **MIDI-управление**: CC1/CC16 → X, CC2/CC17 → Y; ноты 36–43 на 10-м канале
    запускают слайсы 1–8. Работает с любым MIDI-контроллером пэдов.
  - **Луп → паттерн**: кнопка «→ Паттерн» переносит записанную фразу в банк A–D
    выбранной машины как обычные ноты (шаг, высота, длительность, velocity),
    с режимами «заменить» и «добавить».
- Горячие клавиши: `Space` — play/stop, `Z–M`/`Q–U` — клавиатура, `A–K` — подушки BeatBox.
- Нота хранится как `{ at, m, len, v }` — шаг, высота, длина в шагах, громкость.

## Про VST и библиотеки Nexus (reFX)

Браузер не может загружать нативные VST/VST3 и закрытые банки вроде Nexus
(`.nks` / `.ncw`): у веб-страницы нет доступа к плагинам ОС, а формат reFX
расшифровывается только самим Nexus. `Nexus 5 v5.1` — это тот же плагин/хост,
он тоже не «открывает» свой звук для браузера.

**Рабочий мост — экспорт MIDI.** Кнопка «Экспорт MIDI» пишет SMF type 1:

- один трек на каждую машину (имя трека = имя машины);
- ударные BeatBox раскладываются на 10-й MIDI-канал по GM-карте;
- длительности нот из пиано-ролла сохраняются;
- сцены A–D разворачиваются в такты аранжировки, как при воспроизведении.

Дальше в DAW: импорт `.mid` → на каждую дорожку ставится Nexus → выбор пресета
из библиотеки → рендер. Из нашего проекта переносится только MIDI (ноты, высоты,
длительности, velocity), звук даёт Nexus.

**Вариант 2 — MIDI-выход в реальном времени.** Кнопка «MIDI» включает Web MIDI,
в разделе «Экспорт» выбирается порт вывода (loopMIDI, IAC, виртуальный порт DAW).
Транспорт студии шлёт note-on/note-off, velocity, длину и часы F8 прямо в Nexus,
открытый в DAW: FL Studio → MIDI Settings → input port → плагин Nexus в Channel Rack.
Ударные BeatBox уходят на 10-й канал, живая клавиатура студии — на выбранный канал.

### Почему нельзя «просто загрузить Nexus как плагин»

`Nexus 5` — это VST3/AU/AAX-плагин и закрытый движок reFX. В FL Studio и других
DAW он грузится, потому что те имеют доступ к нативным плагинам ОС. Веб-приложение
такого доступа не имеет: `.vst3` не запускается в браузере, `.nks`/`.ncw` не
расшифровываются без самого Nexus. Обойти это можно только нативной оболочкой
(Electron/Tauri + VST-хост вроде JUCE), но это уже не веб-страница.

## Файлы

```
index.html      разметка: транспорт, стойка, секвенсор, микшер, экспорт
css/style.css   тёмная тема, адаптив под телефон
js/engines.js   описания машин, параметров и пресетов
js/pattern.js   банк паттернов A–D, сцены и компонент пиано-ролла
js/midi-file.js экспорт Standard MIDI File (для DAW и Nexus)
js/kaoss.js     X-Y синтезатор с лупом и X-Y процессор эффектов (Web Audio)
js/kaoss-ui.js  X-Y пэды, лупы и сетка программ эффектов
js/audio.js     Web Audio: голоса, барабаны, эффекты, офлайн-рендер, WAV
js/ui.js        кнобы, тосты, модалки
js/app.js       состояние проекта, секвенсор, MIDI, экспорт
```
