# game_ai

## Игровой проект

В репозитории оставлены браузерный прототип стратегии, его игровые данные, документация и игровые 2D-ассеты. Архив переноса содержит исходники игры, данные, ресурсы и инструкции для Redot/Godot; он защищён AES-256. Пароль передаётся отдельно от репозитория.

**Скачать архив:** [`artifacts/redot_game_migration_pack.zip`](artifacts/redot_game_migration_pack.zip).

## Запуск

```bash
PORT=3100 node server.mjs
```

Откройте `/game`. Для описания управления и реализованных функций см. [`docs/GAME_PROTOTYPE.md`](docs/GAME_PROTOTYPE.md); этапы разработки — в [`docs/NEXT_STAGES.md`](docs/NEXT_STAGES.md).

## Содержимое

- `viewer/` — интерфейс и демонстрационные страницы игрового прототипа.
- `data/` — карта мира, фракции, классы, предметы, агенты и командиры.
- `assets/` — иллюстрации фракций и юнитов, игровые иконки, анимации, предметы, портреты и объекты карты.
- `docs/` — документация игры, руководство, план переноса в Redot/Godot план режимов королевства/строительства/тактического боя (`docs/KOHLITE_MODES_AND_TACTICAL_BATTLE_RU.md`) и интеграцию новых тактических UI-ассетов (`docs/prompts/NANO_BANANA_2_ASSET_INTEGRATION_RU.md`).
- `scripts/` — сборка/проверка миграционного архива и синхронизация packaged-runtime с браузерной игрой.
- `tests/` — автоматические проверки критических игровых сценариев.

Запустить smoke-проверки игры:

```bash
npm test
```
