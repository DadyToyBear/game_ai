# Redot 26.3 RC2 Mono + мост: Windows x64

Комплект для Windows 11 x64 содержит официальный Redot 26.3 RC2 Mono, существующий Web-редактор RC2 standard, MCP-мост, страницы и оба аддона. Android APK поставляется отдельно. Компоненты не включаются автоматически в проекты. Web и Android сборки — standard, а не Mono.

## Запуск

Установите Python 3.9+ x64 и .NET 8 SDK x64. Mono-редактор требует .NET 8 даже для проектов без C#; иначе он может завершиться аварийно. .NET 8 вышел из поддержки безопасности в ноябре 2026 года — учитывайте это и проверяйте обновления. Сохраните и скопируйте свой проект перед настройкой.

Распакуйте `redot-win11-x64.zip` в отдельную папку. Откройте PowerShell в папке `redot-win11-x64` и выполните:

```powershell
.\start.cmd
# Или сразу открыть проект и включить обмен его снимками:
.\start.cmd 'C:\путь\к\проекту'
```

Мост запускается только на `127.0.0.1:8765`; если порт занят, редактор не запускается. Секрет в терминале вводится локально на `http://127.0.0.1:8765/native.html` и в доверенном MCP-клиенте через переменную `REDOT_BRIDGE_TOKEN`. Не отправляйте секрет в чат и не открывайте порт в интернет. Закрывайте редактор штатно, предварительно сохранив проект; Ctrl+C останавливает только мост. Web-редактор доступен на `http://127.0.0.1:8765/editor/godot.editor.html`; общий список папок и дисков — на `http://127.0.0.1:8765/project-open.html`.

Для Play/Stop и игрового кадра скопируйте `redot-bridge/addons/redot_local_bridge` в папку `addons` копии проекта, включите аддон и добавьте `game_bridge.gd` в Autoload. Скрипт запуска не меняет проект. Для MCP используйте `python redot-bridge/bridge.py mcp` в своём клиенте с тем же секретом. Пошаговые инструкции, ограничения и безопасность — в `redot-bridge/README.md`.

Сетевые диски сначала подключаются в Windows. Web и Android используют ZIP-копии: реестр предотвращает повторную запись распознанной папки, но не устраняет копии и не гарантирует распознавание всех сетевых алиасов. Синхронизация и слияние не автоматизированы; HTTP/HTTPS-облако — только прямая ссылка на доверенный ZIP с CORS. Снимки включают приватные файлы, кроме `.git` и `.godot`. Изображение игры передаётся редкими JPEG-кадрами, запись WebM до 60 секунд без звука; полноценный видеопоток, развёрнутое облако и автоматическое подключение Arena не реализованы. Android-аддон и relay экспериментальные; APK и инструкции — в отдельном Android-комплекте.

`BUILD-PROVENANCE.txt` указывает версию редактора и ревизии компонентов. GitHub Actions использует Windows Server runner, а не физическую Windows 11; результат проверок и актуальный статус смотрите в соответствующем запуске workflow. Ваш проект, аппаратный GPU, C# и внешние сетевые диски могут работать иначе.
