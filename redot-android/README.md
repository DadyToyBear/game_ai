# Redot 26.3 RC2 Android Editor — экспериментальный MCP

Цель первого этапа: редактор работает **на Android**, а MCP-клиент на компьютере управляет запуском основной сцены через USB. APK пока является обычной сборкой редактора Redot: аддон поставляется **отдельно** и устанавливается в проект, а не встроен в сам APK. Это не готовое удалённое соединение с Arena.

## Что работает по замыслу и что ещё не проверено

- `redot_android_mcp` — экспериментальный `EditorPlugin`, ручное подключение через окно Project → Tools → MCP Bridge. Секрет хранится только в памяти редактора, не в `project.godot`.
- Добавлен экспериментальный вариант подключения через свой HTTPS relay без USB — [инструкция](../redot-bridge/relay-deploy/README.md). Внутри готового комплекта она находится в `relay-deploy/README.md`. Relay требует самостоятельно размещённого защищённого сервера и ещё не испытан с телефоном; автоматического подключения к Arena нет.
- `game_status`, `game_play`, `game_stop` доступны через наш локальный MCP stdio-адаптер. Play/Stop ставят задачу в очередь; статус показывает последнее состояние, а не подтверждает успешный запуск.
- Экспериментальный `game_capture.gd` можно вручную добавить в Autoload проекта для тестов: он отдельно запрашивает согласие и секрет внутри запущенной игры и посылает JPEG с игрового viewport через тот же USB-мост. Захват до 2 кадров/с, а страница отображает до 1 кадра/с; это не полноценный видеопоток. Существующие MCP `game_screenshot` и `delete_game_screenshot` работают с последним кадром в памяти моста; удаление не прекращает отправку следующих кадров. Страница может записывать эти редкие кадры в WebM до 60 секунд без звука.
- Передача файлов Android-проекта, автоматическое подключение облачного агента и полноценные трансляция/запись на Android не реализованы.
- Редактор Android, отдельный процесс игры, захват, USB-подключение, сетевые разрешения и команды на реальном устройстве ещё не тестировались. Работа фонового редактора при запущенной игре зависит от Android и конкретной сборки; кадры могут быть пустыми или недоступными.
- Сервер слушает только localhost компьютера. `adb reverse` направляет запросы localhost телефона в localhost компьютера через USB. Не пробрасывайте сервер в интернет и не сообщайте секрет другим людям или в чат.

## Сборка стандартного APK через GitHub Actions

Workflow `.github/workflows/redot-android-editor.yml` собирает исходники `80d31f765b0ead5551c277704e52bb51c515db1f` (Redot 26.3 RC2), архитектура `arm64`. Нужны сеть Android SDK/Gradle, Java 17, SCons 4.10.1 и NDK 29.0.14206865. Код дополнения поставляется рядом с APK, не внутри него. Одна сборка APK уже завершилась успешно, но совместимость с устройством ещё не проверена. Аддон и инструкции в каждом артефакте соответствуют ревизии того запуска; используйте артефакт свежего успешного запуска для новых функций.

Архитектуру телефона можно посмотреть командой `adb shell getprop ro.product.cpu.abi`: APK только для `arm64-v8a`. Минимальная версия Android, указанная исходниками редактора RC2, — API 24 (Android 7); наличие аппаратной и графической поддержки нужно проверить на устройстве.

## Установка и подключение для теста

1. Установите собранный APK на Android из доверенного артефакта. Сборка с debug-подписью может не обновляться поверх редактора с другой подписью. **Не удаляйте существующий редактор, пока не сделали резервные копии проектов.**
2. Импортируйте свой проект в Android-редактор. Скопируйте `addons/redot_android_mcp` из комплекта в папку `addons` проекта и включите плагин в Project → Project Settings → Plugins. Сначала используйте копию проекта.
3. На компьютере установите Python 3.9+, Android Platform Tools (`adb`) и разрешите отладку USB на телефоне. Подключите телефон кабелем и подтвердите запрос доверия. В терминале из каталога комплекта:

   ```powershell
   adb devices
   adb reverse tcp:8765 tcp:8765
   $env:REDOT_BRIDGE_TOKEN = python -c "import secrets; print(secrets.token_hex(32))"
   # Скопируйте только локально; никогда не отправляйте секрет в чат:
   $env:REDOT_BRIDGE_TOKEN
   python bridge.py serve
   ```

   Если `adb` не найден, используйте полный путь к `platform-tools/adb.exe`. Сервер занимает терминал; Ctrl+C завершает его. При отключении USB и повторном подключении проверьте `adb reverse --list` и при необходимости настройте его снова.
4. В Android-редакторе откройте Project → Tools → MCP Bridge, оставьте USB-адрес `http://127.0.0.1:8765`, вставьте тот же секрет и нажмите Connect. При необходимости откройте меню заново, чтобы посмотреть статус. Секрет не сохраняется после закрытия редактора. Android может разрешать или блокировать локальный HTTP в зависимости от сборки; это нужно проверить на устройстве.
5. MCP-клиент на компьютере должен запускать `python bridge.py mcp` с тем же `REDOT_BRIDGE_TOKEN`. Его настройка зависит от клиента; не сохраняйте секрет в репозитории. Альтернативно локально откройте на компьютере `http://127.0.0.1:8765/native.html`, введите секрет и проверьте Play/Stop.

## Экспериментальные кадры игры

В копии проекта вручную добавьте `res://addons/redot_android_mcp/game_capture.gd` как Autoload через Project → Project Settings → Autoload (например, `AndroidGameCapture`). Это отдельный скрипт для запущенной игры, а не редактора. После Play в игре должно появиться окно: введите тот же секрет и нажмите Share, чтобы добровольно включить захват. Игровой процесс отдельный, поэтому пока ввод нужен повторно при каждом запуске; секрет только в памяти, не в `project.godot`. Отказ кнопкой Not now не отправляет кадры. Диалог закрывается до начала съёмки. Остановить отправку можно закрытием игры; отключение страницы или удаление кадра само по себе захват не остановит.

Кадры должны появиться на `native.html` и в ответе `game_screenshot` MCP-клиента на компьютере. Снимок, возвращённый MCP, можно сохранить средствами клиента; это не даёт облачному Arena доступ к локальному мосту. На странице можно скачать кадр или записать редкие обновления в WebM. Сеть, графический рендерер и работа диалога на телефоне ещё не проверены; возможны ошибки, чёрные кадры и остановка редактора Android в фоне. Удалите Autoload перед публикацией проекта. Если в APK/билде нет debug-флага, скрипт намеренно не запустится.

Сервер и MCP-клиент могут находиться в разных терминалах, но обоим нужно передать один и тот же секрет через окружение. Если PowerShell открывается отдельно, переменная автоматически не переносится. Не публикуйте секрет или команды, содержащие его.
