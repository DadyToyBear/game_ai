# ТТХ воинов (Фаза «карточки») - ЧЕРНОВИК

Задача от пользователя (16.11): после завершения генерации персонажей подписать
КАЖДУЮ картинку на русском языке и сделать подробную карточку.

Что должно быть в карточке:
1. Фракция (Кельтские бритты / Викинги / Галлы / Славяне / Римляне)
2. Род войск / класс (лучник, топорщик, мечник, копейщик, пращник, кавалерист,
   лорд, король, принц, полководец, центурион, префект, вождь)
3. Территория и откуда родом (регион, эпоха)
4. Против кого лучше использовать / кто его контрит
5. Характеристики: сила, урон, нападение, защита, наносимый урон (в цифрах)

План реализации:
- `docs/units_ru/` - по одному markdown-файлу на фракцию (15 воинов каждый)
- `assets/cards/<faction>/<class>.jpg` - готовые карточки-изображения с подписью
  на русском ПОВЕРХ картинки (PIL, DejaVuSans, кириллица)
- Сводные таблицы: `docs/units_ru/00_MASTER_TABLE.md` (5 фракций x 15 классов)
- Единый JSON с ТТХ для движка: `data/units_stats.json`

Статус: ждёт завершения Фазы 2 (осталось Славяне 5, Римляне 15).
