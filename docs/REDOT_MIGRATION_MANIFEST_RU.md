# Состав комплекта для переноса в Redot

Комплект создаётся скриптом `scripts/package_redot_bundle.py` и сохраняется в `artifacts/redot_game_migration_pack.zip`. Внутри ZIP файлы расположены в каталоге `redot_game_migration_pack/`.

## Включается

| Пути внутри комплекта | Зачем нужны |
|---|---|
| `README.md`, `package.json`, `package-lock.json`, `server.mjs` | Контекст и запуск исходного браузерного прототипа. |
| `viewer/**` | HTML/CSS прототип и демонстрационные страницы как эталон интерфейса. |
| `build/_game_runtime.js` | Игровые правила браузерной версии, полезные при переносе. |
| `data/**` | Игровые JSON: карта, классы, фракции, предметы, командиры и агенты. |
| `assets/**` | Игровые иллюстрации, иконки, анимации, портреты, предметы и объекты карты. Крупные PNG/JPG в архиве уменьшаются до длинной стороны не более 384 px; рабочие исходники не меняются. |
| `docs/**` | Руководство переноса, промт, документация и поэтапный план режимов королевства/строительства/тактического боя. |
| `scripts/package_redot_bundle.py` | Синхронизирует packaged-runtime с браузерным скриптом и собирает/проверяет комплект. |
| `tests/**` | Автоматические тесты ключевых игровых сценариев. |

В комплект входят SVG-атлас игровых иконок `assets/ui/icons/game_icons.svg`, боевые GIF-анимации 75 сочетаний фракций и классов, а также тактические UI-подложки `assets/ui/battle/battle_panel.png`, `battle_command_button.png`, `round_banner.png` и `hp_bar.png`, полноразмерные иллюстрации отрядов в `assets/units/cards/` и чемпионов фракций в `assets/units/champions/`, а также компактные alpha-прозрачные превью для боя в каталогах `assets/units/cards/battle/` и `assets/units/champions/battle/`. Для tier-art построек используются изображения замков, городов, ферм, рынков и казарм из `assets/worldmap/objects/` с сохранением прозрачности. Исходный Redot-проект здесь ещё не создан: архив содержит браузерный прототип, игровые материалы и пошаговый план переноса.

## Исключается

- Рыболовные материалы и пути с именами, содержащими без учёта регистра `fish`, `fisher`, `fishing`, `burbot`, `рыб` или `рыбал`.
- `.git/`, `node_modules/`, `.venv/`, `.cache/`, `output/`, `build/` и `__pycache__/`.
- Неигровые и дублирующие GIF-превью; боевые GIF-клипы сохраняются.
- Неиспользуемые файлы сборки и экспортов.

После упаковки скрипт повторно проверяет пути на запрещённые имена и выполняет проверку CRC.

## Создание архива

Из корня репозитория:

```bash
.venv/bin/python scripts/package_redot_bundle.py --output artifacts/redot_game_migration_pack.zip
```

Нужны Python 3, Pillow и `pyzipper` (`python -m pip install Pillow pyzipper`). ZIP защищается WinZip AES-256. При создании пароль запрашивается интерактивно; для автоматизации можно передать его через переменную `REDOT_BUNDLE_PASSWORD`. Используйте пароль длиной не менее 12 символов и храните его отдельно от репозитория.

Pillow уменьшает крупные текстуры только внутри архива. Значение 384 px сохраняет читаемость карточек и портретов; для более детального архива можно указать `--max-image-dimension 768`. Дополнительные GIF-превью включаются флагом `--keep-gif-previews`.

Скрипт сообщает количество файлов, размер ZIP и результат проверок. Готовый защищённый архив расположен в `artifacts/redot_game_migration_pack.zip`.
