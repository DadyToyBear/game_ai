### Спрайты ходьбы — как они устроены

Рядом с каждым `*_walk_row.png` лежит `.json`:

```json
{ "frames": 8, "cell_w": 146, "cell_h": 256, "scale": 0.324 }
```

Кадры выровнены по общей «линии земли» и приведены к одному масштабу
(медиана по кадрам), поэтому цикл не дёргается. `*_walk.png` рядом —
исходный кадр генератора (4–8 фигур в один-два ряда), его можно удалить.

Что стоит знать по качеству:

- кавалерия: генератор нарисовал 12 кадров вместо 8 — оставлены 12,
  ход коня читается;
- топорщик: древко двуручного топора занимает почти всю ширину кадра,
  поэтому в ячейку попадают обрезки топора соседа — это заметно только
  на стоп-кадре, в движении не читается;
- пращник и лучник: цикл короткий (движение ног едва заметно), при желании
  можно дорисовать кадры в движке интерполяцией.

### Витрина и проверки

- `assets/SHOWCASE.html` — страница со всеми ассетами (открывается из
  корня репозитория или через `python3 -m http.server`);
- `preview_walk/*.gif` — анимация цикла ходьбы, по статичному листу шаг
  не оценить;
- `tools/walk_quality.py` — численная проверка «живости» листов:
  доля изменившихся пикселей между соседними кадрами (сейчас 35–46%,
  это нормальный шаг).

### Чего в ассетах нет

- 1.1 `sword_card.png` — по файлу промтов это замена существующему спрайту;
  если старый `03_sword_and_shield/walk.png` в игре лучше — оставь его.

## Скрипты (`tools/`)

- `normalize_cards.py` — из широкой генерации делает квадратную карточку:
  режет дубли-панели, выбирает вариант, строит альфу, вписывает в 512×512.
- `slice_icons.py` — нарезает лист иконок на круглые PNG 128×128 с
  прозрачностью и собирает ровный лист в один ряд.
- `checkerboard_to_alpha.py` — заменяет нарисованную «шахматку прозрачности»
  настоящей альфой (понадобился для плашки раунда).
- `slice_walk.py` — собирает спрайт-лист ходьбы: находит фигуры по центрам,
  отбрасывает обрезки оружия соседей, выравнивает масштаб и линию земли.
- `slice_tiles.py` — нарезает лист тайлов по пергаментным зазорам в 8 PNG
  128×128 и собирает проверочный `tiles/_sheet.png`.
- `ui_alpha.py` — убирает чёрный фон у элементов UI; три режима:
  `crop` (обрезать поля рамки), `ellipse` (кнопки — альфа по овалу обода),
  `alpha` (общий случай). Кнопки нарезаны режимом `ellipse`.
- `walk_quality.py` — метрика подвижности кадров в спрайт-листе.
- `make_walk_previews.py` — GIF-превью циклов ходьбы.
- `make_showcase.py` — сборка `assets/SHOWCASE.html`.
- `imgtools.py` — связные области без scipy (общая зависимость).

Примеры запуска — в docstring каждого скрипта. Требуется `pillow` и `numpy`.
