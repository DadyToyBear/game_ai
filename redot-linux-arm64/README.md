# Redot 26.3 RC2 Mono + мост: Fedora Linux ARM64

Комплект содержит официальный нативный редактор **Redot 26.3 RC2 Mono ARM64** и существующие экспериментальные мост, MCP, Web-редактор RC2 standard и оба аддона (desktop и Android). Компоненты не превращаются автоматически в готовое облако и не включаются в проекты без вашего согласия. Web-редактор и Android APK — standard, не Mono; Android APK отдельно в Android-комплекте. Для C# требуется совместимый .NET SDK; совместимость конкретных C# проектов и плагинов не гарантируется.

## Быстрый запуск

Нужны Fedora Linux на aarch64, графический рабочий стол, Python 3 и установленный браузер. Сохраните проекты и сделайте резервную копию. Скачайте `redot-fedora-arm64.tar.gz` из успешного GitHub Actions artifact, распакуйте `tar -xzf redot-fedora-arm64.tar.gz`, откройте терминал в полученной папке и запустите:

```bash
bash start.sh
# или, чтобы сразу открыть локальный проект и разрешить мосту его снимки:
bash start.sh '/абсолютный/путь/к/проекту'
```

Скрипт создаёт случайный секрет для текущего запуска, выводит его только в терминал, запускает редактор и локальный мост. Вставьте секрет локально на странице `http://127.0.0.1:8765/native.html`. Секрет не отправляйте в чат. Выход из моста по Ctrl+C завершит запущенный им редактор; сначала сохраните работу и закройте игру. Если порт занят, остановите другой мост. Для ручного запуска MCP-клиента нужен тот же секрет в его окружении `REDOT_BRIDGE_TOKEN`; облачный Arena не подключается автоматически. Скрипт не меняет проект, не устанавливает и не включает плагины.

Чтобы управлять нативной игрой и видеть её, на резервной копии установите `redot-bridge/addons/redot_local_bridge` в проект, включите плагин и вручную добавьте `game_bridge.gd` в Autoload. Подробные инструкции и ограничения — `redot-bridge/README.md`. Для MCP запустите `python3 redot-bridge/bridge.py mcp` через ваш MCP-клиент с тем же секретом. Секрет даёт полный доступ к операциям моста, включая регистрацию доступных процессу папок: используйте только доверенный клиент. Не открывайте порт localhost в интернет.

Web-редактор: `http://127.0.0.1:8765/editor/godot.editor.html`. Локальная папка, подключённый средствами Fedora SMB/NFS диск или прямой HTTPS ZIP — через панель редактора или `http://127.0.0.1:8765/project-open.html`. В Web создаётся **копия** в IndexedDB; для Android готовится ZIP-копия. Реестр не дублирует распознанные пути, но разные сетевые алиасы может не распознать. Это не прямая работа в Web с сетевым диском, не live sync и не слияние проектов. HTTPS ZIP требует CORS, доверенного источника и прямой ссылки. Файлы кроме `.git` и `.godot` включаются в снимок, включая секреты. Лимиты и требования безопасности — в инструкции моста.

Имеющиеся кадры — JPEG примерно до 2 кадров/с, запись в WebM до 60 с без звука, не полноценные трансляция и запись. Доступный отдельно relay экспериментален и не развёрнут автоматически. Android-аддон поставляется для совместимости, настройка и APK — в Android-комплекте. Fedora может требовать системные графические/аудиобиблиотеки и драйверы; реальное GPU, Wayland/X11, C#, устройство пользователя и его проект нужно проверять отдельно.

`BUILD-PROVENANCE.txt` содержит версию редактора, исходный Web-артефакт и ревизию моста. Используйте только доверенные проекты и архивы; доступ к сетевым дискам и облачным ресурсам настраивается отдельно в ОС/браузере.
